      How to use Guide Typesetter Studio

      Paste the Markdown of a practical guide (written by an AI or by you) and get a print-ready interior for KDP plus an EPUB. Everything runs in your browser. Nothing is uploaded.

      Quick startWriting syntaxBook detailsStyle and marginsPreviewStyle studio and toolsExportUsing an AI writerTroubleshootingShortcuts

      1. Quick start (5 minutes)

      1. Open the Manuscript tab. A sample guide is already loaded so you can see the result. Click Load sample any time to bring it back.
      2. Replace it with your text: paste into the box, click Upload .md / .txt, or drag a file onto the left panel.
      3. Open Book and fill in title, subtitle, author, publisher line, year and the copyright, disclaimer and dedication texts.
      4. Open Style, choose a preset and your trim size (the page size you chose on KDP).
      5. Check the live preview on the right, then go to Export: Exact Print for the PDF, or Download EPUB.

      Edit text from the preview

      Click any text on a preview page. For body text the studio jumps to that exact text in the Manuscript box and selects it, so you can type the new wording and watch the page update. For the title page, copyright, disclaimer, dedication and About the author, it opens the matching field in the Book tab.

      2. Writing syntax

      Use plain Markdown. The headings decide the structure of the book:

      # Part One: Foundations      (optional part page)
## Chapter title              (every ## starts a new chapter)
### Section title             (a heading inside a chapter)

      Chapters get numbers automatically ("Chapter 1"). Titles that start with Introduction, Preface, Conclusion, Appendix, Glossary, Resources and similar words are not numbered. Text written before the first heading becomes an "Introduction" chapter.

      Callout boxes open with a colon fence and a type, and close with a line containing only three colons. Types: checklist, example, mistake, tip, note, worksheet. The title after the type is optional. Callouts cannot be nested.

      :::tip Label with the words you would say
Write the label you would use when asking someone to find the item.
:::

:::checklist Room diagnosis
- [ ] First item (prints as an empty checkbox)
- [ ] Second item
:::

      A worksheet callout adds blank ruled lines for the reader to write on.

      Tables use standard Markdown. For a caption, put a line starting with Table: directly above the table, with one blank line between them. Tables and figures are numbered per chapter (Table 2.1, Figure 3.2) and the header row repeats if a table runs over a page.

      Table: Weekly schedule

| Day | Focus | Time |
|---|---|---|
| Sunday | Entry | 10 minutes |

      Images: click Add image (PNG, JPEG, GIF, WebP or SVG, max 5 MB each). A line like ![Caption](img:img1) is inserted at the cursor. Replace the caption text. The image is stored inside your project, so it is also included in the EPUB.

      A line with only --- becomes a decorative ornament divider. Bold, italic, lists and numbered lists work as usual. Raw HTML is shown as text, not run.

      Under the text box you see word count, estimated page count, reading time, and warnings: paragraphs longer than 180 words (hard to read in print) and callouts you forgot to close.

      3. Book details

      The Book tab builds the front matter: title page, copyright page, disclaimer page, dedication and contents, then the back matter: index of figures and tables (switch it on in Style), About the author and Also by. Leave a field empty and that page is skipped. In the copyright text, {year}, {author}, {publisher}, {edition} and {title} are replaced automatically. Edit the default copyright and disclaimer so they fit your book and country.

      4. Style, trim size and margins

      • Style gallery: 13 complete looks (Classic Serif, Clean Modern, Farmhouse, Compact Reference, Large Print, Heritage Almanac, Bold Editorial, Field Manual, Swiss Minimal, Vintage Journal, Workbook, Literary, Coastal Calm). Each card is a live mini page. Click one, then fine-tune any setting underneath. Your trim size and front/back matter choices stay when you switch.
      • Trim size: choose the exact size you will pick in KDP (ten standard sizes from 5 x 8 to 8.5 x 11 in).
      • Chapter opener: eight layouts. Drop caps, justified text and chapters start on a right page are toggles. Starting on a right page adds blank pages, which is the traditional book layout. Turn it off to save pages.
      • Accent color: ten colors or any custom color. Black prints cheapest. If a color is too light for text, headings use a darker shade of it automatically.
      • Margins are automatic. The inside (gutter) margin follows your page count: 24-150 pages 0.375 in, 151-300 0.5 in, 301-500 0.625 in, 501-700 0.75 in, 701-828 0.875 in. Outside, top and bottom are at least 0.5 in. Pages are mirrored for left and right. The studio re-checks the page count after typesetting and adjusts if you cross a limit. Always verify against current KDP guidelines.

      5. Using the preview

      The preview is the real paginated book, not an approximation. Page shows one page, Spread shows facing pages like an open book, All shows every page small. Use the arrows or type a page number, and the zoom buttons or Fit. Live re-typesets a moment after you stop typing. For very long books switch Live off and press Typeset now when you want an update.

      Style studio and tools

      • 13 font pairings (Garamond, Baskerville, Merriweather, Source, Crimson, Bitter with Oswald, DM Serif, Spectral, Atkinson Hyperlegible, Courier Prime and more). Fonts download only when you pick them.
      • Components: choose how section headings, callout boxes (boxed, soft tint, label tab, header band, minimal), quotes and tables look. Number your sections (3.2), add an “In this chapter” box under each chapter opener, use a small-caps lead-in, and pick a raised or boxed drop cap.
      • Page: custom outside, top and bottom margins, four running-head styles, four page-number styles and four title-page designs (classic, left with bar, framed, color band).
      • Front and back matter: half-title page, contents with sections, a “thank you, please review” page, up to 10 blank notes pages (ruled, dotted or grid) and an option to end on an even page count.
      • My styles: save your whole look under a name and apply it to any book later (kept in this browser).
      • Navigator: the button above the preview opens page thumbnails and a clickable outline of parts, chapters and sections with their page numbers.
      • Spread view shows facing pages with a gutter shadow and a page-turn animation. The stage menu changes the backdrop (warm, slate, night, light).
      • Insights tab: word counts, reading time, reading ease and grade level, a chapter-length chart, and print checks on the real pages: page count range, contents numbers, pictures under 150 DPI, half-empty pages, stranded headings, blank pages and font loading.
      • Editor tools: a formatting bar (bold, italic, headings, lists, checklist, quote, link) and Find and replace above the manuscript. Smart quotes and dashes are applied to the book without changing your text.
      • Command palette: press Ctrl/Cmd+K, type a few letters and press Enter to change a preset, a font, an option, jump to a chapter, switch view or export.

      6. Exporting

      Print PDF (Exact Print). Click it and a new tab opens with the paginated book. Wait for "pages ready", then press Print / Save as PDF and set:

      • Destination: Save as PDF
      • Margins: None (the margins are already inside the pages)
      • Background graphics: On
      • Headers and footers: off, Scale: 100

      Use Chrome or Edge for the exact trim size. Allow pop-ups if the tab does not open. Upload the saved PDF to KDP as your manuscript.

      EPUB 3. A reflowable ebook for Kindle and other readers. It has no fixed page numbers or running headers, which is normal for ebooks. Run the free EPUBCheck tool before submitting to a store.

      Cleaned markdown tidies spacing and closes open callouts. Front matter pack is a text file with all your front and back matter plus print specs, handy for your KDP listing. Save project keeps everything (text, settings, images) in one .json file. Load project restores it. The browser also autosaves in the background.

      7. Getting the AI to write in this format

      Paste this at the start of your AI chat, then ask it to write your guide:

      Write the book in Markdown. Use "## " for each chapter and "### " for sections.
Use these boxes where useful, each closed with a line of three colons:
:::checklist Title, :::example Title, :::mistake Title, :::tip Title, :::note Title, :::worksheet Title
Write checklist items as "- [ ] item". Put "Table: caption" above every table.
Do not use HTML.

      8. Troubleshooting

      • Preview says libraries did not load: you are offline or a script is blocked. Reconnect and reload.
      • A callout shows as plain text: the type is misspelled or the closing ::: line is missing.
      • Table caption missing: leave a blank line between the Table: line and the table.
      • Image shows [missing image]: the id in img:... does not match an uploaded image. Check the list under the text box.
      • Too many blank pages: turn off "Chapters start on a right page".
      • Print tab does not open: allow pop-ups for this page.
      • PDF page size is wrong: use Chrome or Edge and set Margins to None.
      • Autosave unavailable: your browser blocks storage. Use Save project regularly.

      9. Keyboard shortcuts

      Ctrl/Cmd+Z undo, Ctrl/Cmd+Shift+Z redo, Ctrl/Cmd+S save project, Alt+Left/Right previous/next page, Alt+1 to Alt+5 switch panels, Ctrl/Cmd+K command palette, Alt+P Exact Print, Alt+E EPUB, Alt+R typeset now, F1 this guide, Esc close.
