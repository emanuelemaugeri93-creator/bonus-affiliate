How to use Mirror Beams

1

Generate your deck

Set the puzzle count (1-40), pick a difficulty - it sets the board size, beams and mirror density for you - or override board, beams and density manually. Press Generate. Puzzles build one per tick with a progress bar, and every beam is verified by code before it ships.

2

Style it live

Pick a preset or tap a swatch, edit title and subtitle, header, border, cell style, background pattern and answer-key style. Every control updates the preview instantly; use Apply Style Changes to re-render everything at once.

3

Preview and navigate

Toggle Puzzle View / Answer View, switch between single, spread, 3-up and 2x2 layouts, and zoom 10-130%. Use Previous / Next and the sheet counter; the meta line shows size, beams, difficulty and seed. In Answer View, hover a beam to highlight it.

4

Reshuffle single sheets

Select a sheet and press Shuffle layout to regenerate only that puzzle. Sheets the generator cannot verify after 60 tries carry a visible red flag - never a silent fake.

5

Export your book

Download Exact PDF renders every sheet at 3x: puzzles first, then the answer key; the file name comes from the worksheet title. Exact Print opens a print-ready document where each sheet is exactly one page - in the system dialog keep the default size and switch off headers and footers. For KDP black-and-white interiors use the Print-safe B/W preset.

6

Tips

Readers trace each numbered beam and write the letter where it exits - some letters are decoys. The seed in the footer reproduces that exact puzzle. Press H anytime to reopen this guide.
