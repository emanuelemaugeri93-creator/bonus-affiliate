📖 How to Use This Dossier ▼
1Select an Event — Choose from 47 historical events. Each comes with 4-8 authentic primary sources pre-loaded.
2Filter by Source Type — Check the types you want: telegrams, testimony, letters, technical records, newspapers, or official orders.
3Set Analysis Depth — Surface for basic 5W questions. Deep for subtext, omissions, and dramatic irony. Writer's for chapter application.
4Choose Classification — Select a dossier stamp: CLASSIFIED, TOP SECRET, RESTRICTED, etc. It appears as a watermark on every exhibit.
5Generate & Analyze — Creates a print-ready dossier. Each exhibit has its own analysis section. Rate source credibility using the star scale.
💡 Pro Tip: The most valuable skill for immersive history writers is reading between the lines of primary sources. Ask: what does this source NOT tell us? What did the author not know at the time?
