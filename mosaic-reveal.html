How to use Mosaic Reveal

1

Generate your deck

Set the puzzle count (1-40), pick a difficulty, grid size and theme pack - or choose one exact shape. Press Generate. Each puzzle is solved by code and kept only if it has exactly one solution.

2

Style it live

Pick a preset or tap a swatch, edit titles, header, border, background and answer-key style. Every control updates the preview instantly. Cell shape changes how filled squares look on the answers.

3

Test-solve on screen

Click any cell on a puzzle page to fill it in and test the logic yourself. This never touches the export - it is only your scratch pad.

4

Preview and export

Toggle Puzzle / Answer View, browse layouts and zoom, reshuffle single sheets with Shuffle layout. Download Exact PDF renders puzzles first, then the key; Exact Print gives one page per sheet. Use Print-safe B/W for KDP interiors.

5

Tips

Each number counts filled squares in its 3x3 block, itself included. Readers answer What is it? under the board; the picture name appears only on answer pages and only if the toggle is on. The seed in the footer reproduces that exact puzzle.
