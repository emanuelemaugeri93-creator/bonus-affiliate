HOW TO USE THIS TOOL

This blueprint translates your visual difficulty settings into a complete, detailed prompt directive ready for ChatGPT, DALL·E 3, Midjourney, or any AI image generator. Follow these steps:

  1. Set Glitch Count — Click the evidence tag tiles (3–8) to choose how many anachronistic objects will be hidden in the scene. More glitches = harder puzzle.
  2. Adjust Hide Levels — For each glitch, toggle between Easy (in the open), Medium (partially hidden), or Hard (very well hidden). This controls how challenging each individual glitch is to find.
  3. Select Target Age — Choose the age range for your puzzle audience. This influences the complexity of the scene description and the subtlety of the hiding spots.
  4. Dial Scene Density — Use the slider to set how packed or sparse the background elements are. The dot grid preview shows you the density visually. Sparse = minimal distractions; Packed = busy, detailed environment.
  5. Choose Color Mode — Toggle between Full Color or Black & White depending on whether you want a vibrant printable or an ink-friendly coloring-style page.
  6. Add Special Instructions — Use the text area to add any unique twist (e.g., "make one glitch only visible when the page is tilted", "include a friendly dinosaur guide character", etc.).
  7. Watch the Gauge — The Difficulty Score gauge updates live as you adjust settings, showing whether your puzzle is Easy, Medium, Hard, or Expert level.
  8. Copy the Directive — The prompt box at the bottom generates a brand new, detailed scene description every time you change any setting. Click Copy Directive and paste it into your AI image generator to create your puzzle page.

Pro Tip: Every adjustment triggers a completely fresh scene description — different settings, atmospheres, hiding details, and special effects — so you'll never get the same prompt twice. Use Reset to return to default settings.
