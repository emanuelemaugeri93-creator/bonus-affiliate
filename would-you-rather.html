How to Use This Tool

Quick Start

1. Configure your journal in the left panel (title, categories, tone, page count).
2. Click Generate Book to create your first draft.
3. Click any text on the page to edit inline.
4. Use the right panel to adjust fonts, colors, split-page layout, and icons.
5. Export as PDF or images when ready.

Left Panel - Book Setup
  • Journal Details: Title, subtitle, and author/publisher name.
  • Dilemma Category Focus: Toggle any of the 7 categories on or off. Pages are distributed evenly across whichever categories are checked.
  • Tone: Light & Fun leans toward playful dilemmas, Deep & Reflective leans toward Values & Ethics and weightier choices, Balanced Mix blends both.
  • Page Count Target: Number of dilemma pages (30-60).
  • Paper Size: US Letter, Square, or A4.
  • Include Sections: Toggle cover, copyright, how-to, dilemma pages, reflection summary, "What This Reveals About Me," and back matter.
  • Page Tools: Add a new dilemma page, delete, move, or reset text on the current page.
Right Panel - Design
  • Typography: Pick title and body fonts and adjust size sliders.
  • Colors: Accent and secondary color pickers, plus quick palettes.
  • Split-Page Layout Style: Vertical Split, Horizontal Split, or Card Stack for how Option A/B are presented.
  • Icon Set: Toggle small category line-icons on or off.
  • Page Border Style: Soft Rounded Frame, Simple Rule, or No Border.
  • Save & Load: Manual save/load buttons; autosave also runs on generation.
Center Canvas
  • Navigation: Use arrow keys or the on-screen buttons. Keyboard works when not editing text.
  • View Mode: Toggle Single Page or Spread (two pages side-by-side).
  • Zoom: 50-150% via the top bar controls.
  • Thumbnails: Click to jump to any page; hover to see a delete button.
Inline Editing

Click any text (title, subtitle, options, reflect prompts) to edit directly. Edits are saved automatically as you type. Use Page Tools - Reset Page Text to restore defaults for the current page.

Export & Print
  • Export PDF: Renders all pages at your selected paper size into a single PDF.
  • Export PNG/JPG: Downloads each page as a separate image file.
  • Print: Opens the browser's print dialog with print-optimized CSS.
Keyboard Shortcuts
  • Left Right Navigate pages (when not editing text).
  • H Toggle Help menu.
  • Ctrl + S Save project manually.
Tips
  • Try Card Stack layout for a more playful, magazine-style feel.
  • Horizontal Split works especially well on Square paper.
  • Mix categories for variety, or focus on one (like Values & Ethics) for a themed journal.
