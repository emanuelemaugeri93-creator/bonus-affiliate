How to Use This Tool

Quick Start

1. Paste the text of your Dynasty_Ledger.md file into the Import Ledger box on the left (or click Load Sample Ledger to try it instantly).
2. Click Parse Ledger - you'll see a confirmation of how many characters, secrets, and timeline events were found.
3. Switch between the three views using the tabs above the canvas.
4. Click any node in any view to see its full details in the side panel.

What Gets Parsed
  • Family Tree section: lines like "Name (1802-1871), role; married Spouse (birth-death) in Year; Branch Name." Branch headers (e.g. "Nathaniel Branch - The Ironwood Branch") set the default branch for characters that don't state one explicitly.
  • Secrets Ledger section: blocks starting with **S1 - Title** followed by **Buried choice:**, **Knows:**, **Suspects:**, **Surface cost:**, and **Status:** lines.
  • Era Timeline section: period headers like "Founding and First Division, 1855-1934" followed by lines like "1861 - Event description."
If Something Doesn't Parse

Lines that don't match the expected pattern are listed under the parse status as warnings, so you can fix the formatting and re-paste, or add that character/secret manually using Manual Entry Fallback in the left panel.

The Three Views
  • 🌳 Family Tree: generations stack top to bottom; married couples sit side by side with a connecting line; deceased characters show a † mark. Drag to pan, use the +/- buttons to zoom, click a node for details.
  • 📅 Era Timeline: events plotted left to right by year, grouped into colored era bands; character lifespans appear as bars beneath the axis, colored by branch. Click an event marker for its full description. Scroll horizontally for long timelines.
  • 🔒 Secrets Map: each secret sits in the top grid, colored by severity (auto-guessed from its Surface Cost text, editable per secret). Solid lines connect to characters who "Know" it, dashed lines to those who "Suspect" it.
Filters

Use the Generation Range slider, the Show Deceased toggle, and the Branch Visibility checklist in the left sidebar to focus on part of a large tree - handy once a saga reaches 15+ characters.

Saving Multiple Sagas

Click 💾 Save as New Saga to name and store the current data. Use the dropdown next to it to switch between sagas you've already saved - everything persists in this browser automatically.

Printing

The 🖨️ Print button prints whichever view is currently active, with the sidebar and controls hidden - handy as a physical reference to pin up while writing.
