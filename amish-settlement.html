Amish Settlement File Generator — Detailed Guide
What this app does

Generates unlimited, internally-consistent settlement files — settlement name, real-region placement, correct surnames, bishop, buggy color, and district rules — ready to paste into Amish Empire as your Story Bible starting input. Solves the blank-page moment at the start of every new book/series.

How the unlimited engine works

Every click combines: 26 first-words × 26 second-words settlement names (20+ plausible combos) + 6 real regions (Lancaster/Holmes/Elkhart/Geauga/Allen/St. Mary's) with 20 correct surnames each (120+ total) + 5 affiliations (Old Order → Swartzentruber) + 20+ bishop first names + 4 buggy colors (region-correct: Lancaster gray, Holmes black, Allen white) + 20+ district rules (Technology/Dress/Transportation/Community). That's millions of coherent files — plus you can lock Region and reroll, or type a custom settlement name.

Step-by-step
  1. Pick Region (or 🎲 Random) — this locks the surname bank and buggy color to real regional accuracy.
  2. Set Tightness (1-5) — biases affiliation: 1-2 → Beachy, 3 → Old/New Order, 5 → Swartzentruber/Andy Weaver.
  3. Click 🎲 Generate — get settlement name, bishop (surname from that region), buggy, 8-10 surnames, 4-6 rules, flavor note.
  4. Use 🔒 Lock Region to keep the same real region while rerolling for Book 2.
  5. 💾 Save to library (persists via localStorage) and 📋 Copy as Setup Input to paste into Amish Empire.
Pro tip: The Correct Surnames list is the most valuable output — it directly prevents the name-drift error the source product warns about. Use only those surnames for Amish families in that settlement. For infinite variety, type a custom settlement name in the editor below and hit Generate.
