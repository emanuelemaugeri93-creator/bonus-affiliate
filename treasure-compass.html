How to use Treasure Compass

1

Generate your maps

Set the puzzle count (1-40), difficulty, theme, size and direction style. Press Generate. Every route is simulated by code and every answer is exact.

2

Read the map

Columns run A to L, rows 1 to 12. Start at the ship, follow the Captain's Orders square by square, dodge the rocks. On Expert maps, whirlpools teleport you without warning.

3

Style it live

Pick a preset, toggle coordinates and the torn edge. Every control updates the preview instantly. All icons are drawn vectors, so exports look identical everywhere.

4

Preview and export

Toggle Puzzle / Answer View - on answers, hover an instruction to highlight its path segment. Download Exact PDF renders puzzles first, then the key; Exact Print gives one page per sheet. Use Print-safe B/W for KDP interiors.

5

Tips

Write the landmark and its coordinates on the answer lines. The bonus counts orthogonal squares only. The seed in the footer reproduces that exact map.
