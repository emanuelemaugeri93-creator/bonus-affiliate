    How to use Practical Diagram Studio

    Make clean, print-ready diagrams for the inside of a practical nonfiction book: pick a template, enter your sizes and labels, choose a style, and export SVG, PNG (300 DPI), PDF or a whole ZIP set. Everything is drawn in your browser. Nothing is uploaded.

    Important: these diagrams are illustrative, not engineering plans. They are not installation instructions and they do not show wiring. Always tell readers to follow local codes, safety rules and manufacturer instructions.

    1. Quick start

    1. Template: click one of the 16 diagrams. The canvas updates at once.
    2. Size & Labels: pick imperial or metric, then type your real sizes and your own label words. The Key numbers box shows the math (area, volume, watts).
    3. Style: choose Print-safe B/W (hatch patterns, cheapest to print), Earth Tones, Blueprint, Chalkboard or Colorblind-safe.
    4. Figure: set the chapter number, write the caption and choose the print width for your book size.
    5. Export: download SVG, PNG or PDF, or click Add to set for each figure and export them all as a ZIP.

    2. The 16 templates

    • Use the category buttons and the search box in the Template tab to find a diagram quickly.
    • Raised Bed Layout: bed length, width and height, planting grid squares, labeled zones, optional path, side cross-section and scale bar.
    • Garden Plot Plan: several beds and paths inside a plot, with compass arrow, sun side and scale. If the beds do not fit you get a warning.
    • Three-Bin Compost Layout: bin sizes, labeled stages, turn arrows and airflow arrows, with volume per bin.
    • Rain Collection Flow: generic label-only schematic from roof to tank, with an estimate of the water one rain event collects.
    • Pantry Shelf Rotation: shelves and item slots with first-in, first-out arrows and your own item labels.
    • Water Storage Plan: a grid of containers with the total volume and how many days it covers for your household.
    • Power Budget Flow: block diagram from source to loads with the watts you enter. It shows numbers and arrows only, never wiring.
    • Small Coop Floor Plan: coop, run, door, nest area and roost bar with dimensions only.
    • Row and Plant Spacing: rows and plants inside a bed, with spacing dimensions and the plant count.
    • Planting Calendar: a month grid showing when each crop is sown and harvested. Lines look like Tomatoes, 3-5, 7-10 (sow months, harvest months). You can start the chart in any month.
    • Seed Starting Tray: tray with rows and columns grouped by variety.
    • Fence and Trellis Elevation: posts, rails and infill (pickets, wire, lattice) with post count and spacing.
    • Paddock Rotation Plan: paddocks in order with days in each and the resulting rest days.
    • Compost Layers: cross-section with your browns and greens parts and the resulting percentages.
    • Daily Energy Balance: bar chart of what each load uses per day against what the solar array makes. Lines look like Fridge, 150, 8 (watts, hours per day).
    • Shelf-Life Timeline: bars of how long each food item lasts, with review marks. Lines look like Rice, 48 (months).

    3. Sizes, labels and units

    Type numbers in the unit you picked. Switching Imperial/Metric converts what you see (the real value is never rounded away, so switching back and forth does not drift). Labels are plain text: you can type any characters, they are never run as code. Long labels are shortened automatically if they would overlap, and a yellow warning appears above the canvas when a label cannot be placed.

    For lists (zone labels, pantry items, power loads) separate items with commas, or one per line for loads in the format Name, watts.

    4. Styles

    Print-safe B/W uses hatch patterns instead of gray or color fills, so it prints sharply on black-and-white KDP interiors. Colored styles are for ebooks and color interiors. Colorblind-safe uses a palette that stays readable for color-blind readers. Optional soil texture adds random speckles, repeatable with the seed number.

    5. Figures, numbering and captions

    The figure number is automatic: Figure chapter.number, for example Figure 3.2. Set the chapter number; the studio counts the figures of that chapter in your set. The caption and an optional source line can sit inside the image. The footer note "Illustrative diagram. Follow local codes and manufacturer instructions." is on by default for the water and power templates. Choose a print width that matches your trim size (usable width after margins).

    6. Figure set and pages

    Click Add to set to save the current figure. Click a name to edit it, then Update selected. Duplicate copies a figure so you can change a few numbers. Use Up/Down to reorder and x to delete. Numbers update by chapter and order.

    In the Figure tab choose how many figures go on each page (1, 2 stacked, or 4 in a 2 x 2 grid) and whether pages are numbered. Click Set pages above the canvas to see the printed pages, and use Multi-page PDF of the set in Export to download them.

    Extra figure options: Label size (small, normal, large), Transparent background for SVG and PNG, and Alt text that is stored in the SVG for screen readers and ebooks.

    7. Exporting

    • SVG: one clean vector file (keeps the physical width, includes a title and description for accessibility).
    • PNG 300 DPI: exactly width in inches x 300 pixels, with 300 DPI stored in the file.
    • PDF page: a page of your trim size with the figure centered.
    • Multi-page PDF: the whole figure set, 1, 2 or 4 figures per page, with optional page numbers.
    • ZIP: every figure of the set, plus index.csv listing number, caption and file name.
    • Save project / Load project: one .json file with everything. The browser also autosaves.

    8. Using the files in a KDP book

    For print, use PNG at 300 DPI or place the SVG/PDF in your layout tool at the width you chose. For EPUB, SVG or PNG both work. Keep captions in the image or in your book text, not both.

    Editing the text inside a figure

    Click any text in the figure on the canvas (labels, title, caption, legend, numbers). A small box appears. Type the new text and press Enter. Press Esc to cancel. Your edits are saved with the figure, exported in SVG, PNG, PDF and ZIP, and kept when you change sizes. Use Reset text edits in the Figure tab to restore the original text. If a label is edited and then changed in Size and Labels, that single edit is dropped because the original text changed.

    9. Troubleshooting

    • Label was shortened: shorten your text or widen the print width.
    • "Only X of Y beds fit": the plot is too small for that many beds. Reduce the count or the bed size.
    • Grid hidden: the squares are too small to draw at this width. Use a bigger square size.
    • PNG or PDF fails: reload and allow the page to load its libraries (needs internet for jsPDF and JSZip).
    • Autosave unavailable: your browser blocks storage. Use Save project.

    10. Shortcuts

    Ctrl/Cmd+Z undo, Ctrl/Cmd+Shift+Z redo, Ctrl/Cmd+S save project, Alt+1 to Alt+5 panels, Alt+A add to set, Alt+D set pages, Alt+G grid, Alt+P print preview, Alt+= / Alt+- zoom, F1 this guide, Esc close.
