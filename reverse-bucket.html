How to Use This Tool

Quick Start

1. Configure your journal in the left panel (title, theme, page count, depth).
2. Click Generate Book to create your first draft.
3. Click any text on the page to edit inline.
4. Use the right panel to adjust fonts, colors, and layouts.
5. Export as PDF or images when ready.

Left Panel - Book Setup
  • Journal Details: Title, subtitle, author, and life theme (6 options: General, Career, Family, Travel, Health, Milestones).
  • Page Count Target: Slider from 30-60 pages. The tool auto-distributes prompts from your theme's bank.
  • Reflection Depth: Light (1 prompt/page) or Deep (2 prompts/page side-by-side).
  • Paper Size: US Letter, Square, or A4. Changes canvas dimensions instantly.
  • Page Layout: Choose layout variants for guided pages, cover, timeline, and gratitude sections.
  • Include Sections: Toggle cover, copyright, how-to, TOC, guided pages, timeline, gratitude, back matter, and page numbers.
  • Page Tools: Add guided pages, delete, move up/down, or reset text on the current page.
Right Panel - Design
  • Typography: Pick title and body fonts, adjust size sliders, and set line spacing for writing areas.
  • Colors: Ink and accent color pickers, plus 4 quick palettes (Golden Hour, Sage Dusk, Dusk Violet, Terracotta).
  • Page Border Style: Soft Rounded Frame, Simple Rule, or No Border.
  • Icon Set: Toggle warm line-icons (sun, path, heart, star) on guided pages.
  • Save & Load: Manual save/load buttons; autosave also runs on generation.
Center Canvas
  • Navigation: Use arrow keys or the on-screen buttons. Keyboard works when not editing text.
  • View Mode: Toggle Single Page or Spread (two pages side-by-side).
  • Zoom: 50-150% via the top bar controls.
  • Thumbnails: Click to jump to any page; hover to see a delete button.
Inline Editing

Click any text (title, subtitle, prompts, notes, timeline entries) to edit directly. Edits are saved automatically as you type. Use Page Tools - Reset Page Text to restore defaults for the current page.

Export & Print
  • Export PDF: Renders all pages at your selected paper size into a single PDF.
  • Export PNG/JPG: Downloads each page as a separate image file.
  • Print: Opens the browser's print dialog with print-optimized CSS (no UI elements printed).
Keyboard Shortcuts
  • Left Right Navigate pages (when not editing text).
  • H Toggle Help menu.
  • Ctrl + S Save project manually.
Tips
  • Use Two-Column Split layout for Deep Reflection mode to see both prompts side-by-side.
  • Try the Icon Sidebar layout for a more editorial, magazine-style feel.
  • Enable Table of Contents for a professional touch on longer journals.
  • Adjust Line Spacing if you plan to print and write by hand (18-24px is comfortable for most).
