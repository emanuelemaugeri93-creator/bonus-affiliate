How to use this tool (click to hide / show)
  1. Left column: add one or more of the 20 ready-made shop packs (12 fictional objects each, 6 genuine and 6 fake) or start a blank pack. Select an item to edit it.
  2. Middle column: edit the object: name, icon, genuine or fake, price, tint and wear. Click the live preview to place 3 to 5 inspectable spots and write a short clue for each.
  3. Right column: set the game rules, texts and theme, then press Play-test and download the single .html game.

All objects are fictional icons. Clues are historically inspired and simplified for play: this is a game, not an authentication guide. Your work autosaves in this browser.
