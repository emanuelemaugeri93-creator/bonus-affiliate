How to Use This Tool

Quick Start

1. Configure your journal in the left panel (title, categories, pair count, difficulty mix).
2. Click Generate Book to create your first draft.
3. Click any text on the page to edit inline.
4. Use the right panel to adjust fonts, colors, decoration, and guess-box style.
5. Export as PDF or images when ready.

Left Panel - Book Setup
  • Journal Details: Title, subtitle, and author/publisher name.
  • Category Focus: Toggle any of the 7 estimate categories on or off. Pairs are distributed evenly across whichever categories are checked.
  • Page Count Target: Number of estimate/reveal pairs (30-60), matching a typical trivia/activity-book length.
  • Difficulty Mix: Easy & Fun leans toward accessible facts, Challenging leans toward obscure ones, Mixed uses a natural blend.
  • Paper Size: US Letter, Square, or A4. Changes canvas dimensions instantly.
  • Include Sections: Toggle cover, copyright, how-to, estimate/reveal pairs, score summary, and back matter.
  • Page Tools: Add a new guess pair, delete, move, or reset text on the current page.
Right Panel - Design
  • Typography: Pick title and body fonts and adjust size sliders.
  • Colors: Accent and secondary color pickers, plus quick palettes.
  • Page Decoration: Slider controls how many playful geometric shapes appear on each page.
  • Guess Box Style: Circle Target, Simple Line, or Bracket Frame for the "My Guess" writing area.
  • Page Border Style: Soft Rounded Frame, Simple Rule, or No Border.
  • Save & Load: Manual save/load buttons; autosave also runs on generation.
Center Canvas
  • Navigation: Use arrow keys or the on-screen buttons. Keyboard works when not editing text.
  • View Mode: Toggle Single Page or Spread (two pages side-by-side) - handy for viewing a guess page next to its reveal.
  • Zoom: 50-150% via the top bar controls.
  • Thumbnails: Click to jump to any page; hover to see a delete button.
Inline Editing

Click any text (title, subtitle, questions, answers, surprise notes) to edit directly. Edits are saved automatically as you type. Use Page Tools - Reset Page Text to restore defaults for the current page.

Export & Print
  • Export PDF: Renders all pages at your selected paper size into a single PDF.
  • Export PNG/JPG: Downloads each page as a separate image file.
  • Print: Opens the browser's print dialog with print-optimized CSS (no UI elements printed).
Keyboard Shortcuts
  • Left Right Navigate pages (when not editing text).
  • H Toggle Help menu.
  • Ctrl + S Save project manually.
Tips
  • Use Spread view while editing so you can see a guess page and its reveal at the same time.
  • The Circle Target guess box style tends to look great for kids or playful audiences; Bracket Frame feels more editorial.
  • Lower the Page Decoration slider for a cleaner, more minimal print result.
