📖 HOW TO USE (60-SECOND READ)
  1. Set Role → Age slider → Ethnicity → Style, then hit Generate — each click adds one character card to My Cast.
  2. Every prompt follows the 4-part lock: [A] physical description, [B] consistency lock-line, [C] base pose, [D] wardrobe anchor. Copy it verbatim into your image tool — never drop [B].
  3. Watch the ⚠ similarity warnings — two lookalikes break consistency. Reroll the clash (same settings, new face).
  4. Shortcuts: ⚡ Auto-Build Full Cast creates 5 auto-diversified characters at once; 🎲 Surprise Me randomizes all settings.
  5. Save Full Cast when the lineup is locked — the library keeps one cast per series, and 📋 Copy Full Cast Sheet exports the Step 2 input.
Pro tips: use the SAME style value here as in Trope Engine and Segmenter. The first generated portrait becomes the reference — derive all 30 episodes' images from it. Second-generation modifiers (texture, hair detail) are rolled once and frozen per character.
