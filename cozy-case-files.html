How to use Cozy Case Files

1

Build a casebook

Pick 6 to 30 cases and the difficulty levels. Cases ramp from easy to expert, and each one is set in a different cozy place. Press Generate Casebook.

2

One solution, no filler

A logic solver builds every case from a hidden solution, adds true clues until only one answer remains, then removes any clue that is not needed.

3

Your own cast

Add suspect names, items for the cast and a setting of your own with six or more locations. Lines that cannot be used are listed in red.

4

Make a book

Choose a KDP trim and bleed. Book Builder adds title, copyright and how-to-solve pages, case sections, evidence cards and an answer key with the first deductions. Export one PDF or a PNG ZIP. The seed in every footer rebuilds the same casebook.

5

Shortcuts

G generate, A puzzle/answer view, ← → pages, Ctrl+Z undo, Ctrl+Y redo, H help.
