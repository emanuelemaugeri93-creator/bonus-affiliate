How to use Scripture Cipher Studio

1

Generate

Set the puzzle count, difficulty, puzzle types and verse theme, then press Generate (or key G). Every cipher is built and decoded by code, so each answer is exact. The KJV text is public domain.

2

Choose your trim

In KDP Trim Studio pick 6 x 9, 8 x 10, 8.5 x 11 or A4, turn bleed on if your printer needs it, and switch on the guides to see the safe area and inside margin. Layouts resize to fit every trim.

3

Build the book

The Book Builder adds a title page, an editable copyright page, a how-to-play page, theme dividers, the puzzles and the answer section, all numbered correctly. Use Content Lock to decode your own public-domain or self-written quotes instead.

4

Style and brand

Pick a preset (use Print-safe B/W for black interiors), add an optional "Created by" line and the logo mark. Changes show in the preview straight away.

5

Export and save

Download Exact PDF renders every page, answers last. You can also export a PNG ZIP or the current page as SVG. Undo / Redo (Ctrl+Z / Ctrl+Y), autosave, Save .json and the short seed code keep your project safe.

6

Shortcuts

G generate · A toggle answer view · Left / Right change page · Ctrl+Z / Ctrl+Y undo and redo · H this help.
